# Airbnb Clone 🏠

A full-stack **Airbnb Clone** built using **Node.js, Express.js, MongoDB, and EJS**.
This project allows users to view and explore property listings through a simple web interface.

## 🚀 Features

* View all available listings
* View individual listing details
* Dynamic pages using EJS
* MongoDB database integration
* Mongoose for database modeling
* Express.js routing
* Organized MVC-style project structure
* Responsive and user-friendly interface

## 🛠️ Technologies Used

* **Node.js** — Backend runtime
* **Express.js** — Web framework
* **MongoDB** — Database
* **Mongoose** — MongoDB object modeling
* **EJS** — Templating engine
* **HTML/CSS** — Frontend

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/07Dhruvbansal/Airbnb-clone.git
```

### 2. Navigate to the project

```bash
cd Airbnb-clone
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start MongoDB

Make sure MongoDB is running locally on your system.

The project currently connects to:

```text
mongodb://127.0.0.1:27017/wonderlust
```

### 5. Start the server

```bash
node index.js
```

The application will run on the configured local port.
